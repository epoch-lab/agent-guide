# 开源 Agent

本章节聚焦优秀开源 Agent 的工程拆解。

重点不是背功能列表，而是理解它们在架构、可靠性和可维护性上的取舍。

## 对比框架

| 维度 | OpenClaw | Nanobot |
| --- | --- | --- |
| 典型定位 | 复杂任务链路编排 | 轻量化快速实验与接入 |
| 重点价值 | 规划与执行协同 | 低门槛组合与扩展 |
| 关注点 | 可观测性、状态管理、失败恢复 | 模块边界、插件机制、快速迭代 |

## 阅读建议

1. 先读架构入口，画出组件关系图。
2. 再看 Tool Call 相关代码，理解异常处理。
3. 最后看评测或测试目录，判断工程成熟度。

# 基础知识

这一部分用于建立 Agent 工程的共同语言。

没有共同语言，团队常见的问题是开发很快、排障很慢。

## 建议先对齐的三件事

1. `Skill`：可复用能力单元，不是一次性提示词。
2. `MCP`：标准化的上下文与工具通道边界。
3. `Tool Call`：带副作用的执行动作，需要契约和安全限制。

## 推荐阅读顺序

- [Skill](/basics/skill)
- [MCP](/basics/mcp)
- [Tool Call](/basics/tool-call)

## 完成本章节后你应具备

- 用统一词汇描述 Agent 的行为与边界。
- 判断故障发生在提示层、上下文层还是工具层。
- 在编码前先写出最小可行架构。

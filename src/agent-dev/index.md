# 应用开发

这一部分讨论如何把 Agent 从 Demo 推进到可上线系统。

## 三层开发视角

1. **体验层**：用户如何发起任务、查看结果、处理失败。
2. **编排层**：任务如何拆解、路由、并发和回滚。
3. **能力层**：模型、工具、知识库、记忆系统如何协作。

## 本章节目标

- 给出一套可落地的 Agent 应用架构。
- 建立可观测、可回归、可灰度的研发流程。
- 用统一标准评估上线风险与收益。

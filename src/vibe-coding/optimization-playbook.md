# 调优作战手册

这是一套可直接落地的 Agent 调优流程，重点是让每次优化都可解释、可复现。

## 第一步：建立错误字典

先把线上问题归类，再决定优化动作。

- 事实性错误：信息引用不准或幻觉。
- 策略性错误：步骤顺序不合理或遗漏关键动作。
- 执行性错误：Tool Call 失败或恢复路径缺失。

## 第二步：单变量调优

每轮只改一个变量，避免“改了很多但不知道为什么变好/变坏”。

可选变量示例：

- 提示结构（指令顺序、约束表达）
- 模型参数（temperature、top_p）
- 上下文窗口策略（检索条数、截断规则）

## 第三步：建立回归集

回归集至少覆盖三类样本：

1. 高频真实场景。
2. 历史事故样本。
3. 边界与对抗样本。

## 第四步：定义停止条件

当以下条件满足时，停止继续调参并进入发布验证：

- 核心指标连续 3 轮无显著提升。
- 新问题引入率低于阈值。
- 成本与延迟保持在预算内。

## 每周调优节奏示例

| 时间 | 动作 | 产出 |
| --- | --- | --- |
| 周一 | 复盘线上失败样本 | 错误字典更新 |
| 周二-周三 | 单变量实验 | 实验记录与对比报告 |
| 周四 | 回归集验证 | 通过/回退决策 |
| 周五 | 小流量灰度 | 风险清单与下周计划 |

# 在写代码一文不值的时代，我们的核心竞争力是什么？

- 是设计构建复杂系统，做架构的能力。
    - 1.Brainstorm：头脑风暴，讨论要做什么。
    - 2.Map：根据头脑风暴产出 PRD，拆解为 EPIC 和 Story。
    - 3.Act：循环处理这些 EPIC 和 Story。

- 确认系统健壮性，做验收的能力，
    = 用多个 ai 进行“打架“，一个 calude code写代码，一个 codex 找 bug。再人为决定这些bug中哪些是误报，哪些真的是 bug。

#### 设计

核心是不能凭感觉写代码，不能一点点让 ai来磨，这样你做一个连续的、可持续性的。可维护的系统。
你应该让想法 IDEA对应到具体的 SPEC 再对应到具体的代码。每行代码都有迹可循。出问题的地方我们再修改。
